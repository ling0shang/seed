# 0001 项目章程

## 定位
seed 是跨平台 C++ 基础设施练习库，目标是能力提升 + 求职作品集，不对标完整 Boost。

## 标准
C++17 基线，CMake 构建，doctest 测试，GitHub Actions 跨平台 CI，命名空间 `seed`。

## 质量底线
每个核心模块必须有测试、设计说明、边界用例、CI 绿、一次 API 复盘。

## 主线路线
M0 脚手架 → M1 基础工具 + Result + INI 垂直切片 → M2 内存池 → M3 线程池 → M4 协程或精简 Reactor（二选一）

## 明确不做
不对标完整 Boost；不做完整网络服务器；不做 GUI、数据库、复杂序列化；不提前优化；M0 阶段不做 INI、内存池、线程池、网络。

## 里程碑验收
| 里程碑 | 内容 | 验收 |
| --- | --- | --- |
| M0 脚手架 | 仓库、目录、CMake、doctest、CI、README、章程、准入标准、version + trim 小样例 | 本地构建 + ctest 通过，CI 绿，文档齐全 |
| M1 基础底座 | Result/Error、字符串工具、文件读取、INI backend | 完整垂直切片，测试覆盖边界，API 复盘 |
| M2 内存池 | 固定大小/分级分配器、与 malloc 对比、基准测试 | 能讲清内存布局、系统调用、性能取舍 |
| M3 线程池 | 任务队列、同步原语、关闭语义 | 能讲清并发、锁、条件变量、任务调度 |
| M4 选做 | 有栈协程或精简 Reactor | 能讲清上下文切换/epoll/事件驱动 |

## 求职重点
M2 和 M3 是主线卖点；INI 是 M1 的工程质量样板间，不是主打。

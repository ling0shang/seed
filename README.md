# seed

跨平台 C++ 基础设施练习库，用于能力提升与求职驱动。

## 定位

- C++17 基线，CMake 构建，doctest 测试，GitHub Actions 跨平台 CI
- 命名空间 `seed`
- 主线：脚手架 → 基础工具 + Result + INI → 内存池 → 线程池 → 协程或精简 Reactor

## 非目标

- 不对标完整 Boost
- 不做完整网络服务器
- 不做 GUI、数据库、复杂序列化
- 不提前优化
